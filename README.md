# 하루장 (PWA)

하루의 중요한 일을 가볍게 남기는 개인 기록장입니다(v0.9373). 기록과 사진은 폰의 브라우저 저장소에만 저장되고 서버로 전송되지 않습니다(보안 정책 CSP로 외부 통신도 막혀 있습니다). 코드·데이터 구조의 상세는 별도 문서 `harujang-개발참고-v0.9347.docx`를 보세요.

## 파일 구성
- `index.html` 앱 본체(화면, 스타일, 동작 모두)
- `manifest.webmanifest` 설치 정보(이름, 아이콘, 색)
- `sw.js` 오프라인용 캐시. 배포할 때마다 안의 `VER` 값을 올려야 설치된 앱이 새 파일을 받습니다. (`index.html`의 `APP_VER`도 함께 올립니다.)
- `icons/` 아이콘 3개

## 올리기 (GitHub Pages, 처음 한 번)
1. github.com 에 가입하고 로그인합니다.
2. 오른쪽 위 `+` → `New repository`. 이름은 남이 추측하기 어렵게 짓습니다. 예: `harujang-k7x3q`. `Public`으로 만들고 `Create repository`.
3. `uploading an existing file` 링크를 눌러 이 폴더 안의 파일과 `icons` 폴더를 끌어다 놓고 `Commit changes`.
   (zip 파일 자체가 아니라, 압축을 푼 안쪽 파일들을 올립니다.)
4. `Settings` → `Pages` → Branch를 `main`, 폴더를 `/ (root)`로 선택하고 `Save`.
5. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소가 생깁니다.

## 폰에 설치
- 안드로이드(Chrome): 주소를 열고 오른쪽 위 메뉴(⋮) → `앱 설치` 또는 `홈 화면에 추가`. 홈 화면 아이콘으로 실행합니다. 처음 한 번만 인터넷이 필요하고 이후에는 비행기 모드에서도 열립니다.
- 아이폰(Safari만 가능): 주소를 열고 공유 버튼 → `홈 화면에 추가`. Chrome이나 카카오톡 안에서는 설치되지 않습니다. (아이폰 실기기는 확인하지 못했습니다.)
- 설치한 앱과 브라우저 탭은 저장 공간이 따로입니다. 설치 후에는 홈 화면 아이콘으로만 여세요.
- 앱 `보관` 탭의 `앱 설치`에도 같은 안내가 기종별로 나옵니다.

## 사용법
- 오늘 탭: `기록 남기기`(분류, 제목, 장소, 일시, 메모, 사진, 중요), `할 일 추가`(제목, 예정일, 선택 시간). 시간을 넣은 할 일은 `🔔 알림 등록`으로 캘린더에 일정이 채워져 열립니다(안드로이드: 구글 캘린더, 아이폰: 캘린더 파일 .ics). 할 일을 체크하면 "기록하기" 알림이 떠서 한 번에 기록으로 옮길 수 있습니다.
- 기록 탭: 날짜별 목록(전체 보기에서는 독서·여행·학습이 책·여행·학습명별 묶음 카드 하나로 나오고, 누르면 그 묶음이 열립니다. 검색이나 중요 필터를 쓰면 낱개로 나옵니다), 분류 필터, 중요 필터, 검색. 기록을 누르면 먼저 읽기 전용 화면이 열리고 `수정`을 눌러야 고칠 수 있습니다.
- 달력 탭: 월별 기록과 남은 할 일, 이달의 분류별 건수와 거리·비용 합계.
- 보관 탭: 보관 상태(개수, 사용 용량), 글자 크기, 분류 관리, 백업과 복원, 앱 설치, 앱 업데이트, 사용 방법 도움말, 현재 버전.
- 화면 위쪽 줄에는 `하루장 · 기록`처럼 현재 탭 이름이 표시되고, 백업이 필요하면 오른쪽에 `백업 필요`가 나타납니다.
- 분류: 외출, 업무, 만남, 등산, 운동, 여행, 쇼핑, 독서, 학습, 기타 10개로 고정입니다. 분류 관리에서 표시 이름, 순서(▲▼), 숨김만 바꿀 수 있고, 제목 오른쪽 `원래대로`(두 번 눌러 확인)로 처음 상태로 되돌립니다. 분류에 따라 입력 항목이 다릅니다(업무·학습: 시작·종료, 등산·운동: 시작·종료와 거리, 여행·쇼핑: 비용, 독서: 저자와 읽은 쪽).
- 형광: 메모에서 글을 선택하면 선택한 글자 바로 위에 형광 버튼이 나타납니다. 누르면 그 부분이 `==글==`로 저장되어 기록 화면에서 형광색으로 보이고, 다시 누르면 해제됩니다. 색은 보관 탭 `형광색`(노랑·연두·분홍·하늘)에서 고릅니다.
- 글자 크기: 보관 탭에서 보통/크게(약 15% 확대)를 고르면 이 폰에 저장됩니다.
- 여행: `여행명`과 제목이 필수입니다. 입력은 두 줄입니다(첫 줄 `여행명 | 장소`, 둘째 줄 `제목 | 일시`). 여행명 칸 오른쪽 `가져오기`(또는 칸을 누름)로 최근 여행 목록에서 고르거나 새로 씁니다. 새 기록의 여행명은 비어 있고, 여행을 열어 `이 여행에 기록`을 누르면 그 여행명이 들어갑니다. 기록 탭의 여행 필터에서 `여행별`로 묶여 기간, 일수, 기록한 비용 합계, 장소가 나오고, 여행을 열면 기록이 최신순으로 이어집니다. 여행명을 고치면 같은 여행의 기록도 함께 바뀌고, 이미 있는 다른 여행 이름을 고르면 그 기록만 옮겨집니다. 여행명 없이 쓴 옛 기록은 `여행명 없음`에 모입니다. 일정·예산·정산은 이 앱의 범위가 아닙니다.
- 학습: `학습명`(필수, 예: 영어·선형대수)과 제목(자료·범위), 일시, 종료·소요시간, 메모(핵심은 형광), ★(다시 볼 것). 장소는 없습니다. 기록 탭에서 학습을 누르면 `학습별`로 묶여 기간, 회차, 마지막 제목, 누적 학습시간이 나오고, 학습명을 열면 `전체/핵심(형광만)/★` 필터와 `이 학습에 기록`, 내보내기가 있습니다. 같은 학습명의 기록에는 날짜순으로 `N회차`가 자동 표시되며(저장하지 않고 계산), 달력의 이달 합계에 학습시간이 들어갑니다. 학습명을 고치면 같은 학습의 기록도 함께 바뀝니다.
- 독서: 제목과 저자, 읽은 쪽(시작·끝·총), 메모 종류(인용·생각·더알·요약·기타, 기타가 기본), 완독. 인용에는 `+ 내 생각`으로 생각을 함께 남길 수 있습니다. 제목이나 저자를 고쳐 저장하면 같은 책의 다른 기록도 함께 바뀝니다. 제목 줄의 `가져오기`로 읽은 책을 불러오고, 기록 탭에서 독서를 누르면 책별 목록이 열리고, 책을 열면 `이 책에 기록` 버튼으로 같은 책에 바로 이어서 기록합니다. 책 내보내기(마크다운)도 있습니다.

## 백업과 복원
- `보관` 탭 → `글만 백업 저장`(기록·할 일만, 가볍고 빠름, 파일명 `harujang-text-YYYYMM.json`) 또는 `전체 백업 저장`(사진 포함, `harujang-backup-YYYYMM.json`). 글만 백업으로 복원해도 사진은 돌아오지 않고 이미 있는 사진은 그대로 남습니다. 파일 이름은 달 단위이며, 폰의 다운로드 폴더에 저장됩니다(같은 이름이 있으면 (1), (2)가 붙습니다). 구글 드라이브나 PC로 옮겨 두세요. 사진까지 모두 들어 있습니다.
- `다른 곳으로 보내기`는 공유 창으로 바로 보내는 버튼입니다(두 번 눌러 준비→공유). 일부 폰에서 "공유하지 못했습니다"가 뜰 수 있으며, 그때는 파일 저장을 쓰세요.
- `백업 불러오기`는 현재 기록에 합치기입니다. 현재 기록은 지워지지 않고, 새 기록은 추가되며, 같은 기록은 수정 시각이 더 새로운 쪽이 남습니다. 지운 기록도 백업에 있으면 되살아납니다. 끝나면 새로 추가/최신으로 갱신/이미 같음/읽지 못함으로 나눠 결과를 보여 줍니다.
- `읽기용(마크다운) 저장`은 읽고 보관하는 용도이며 복원에는 쓸 수 없습니다.
- 사진 관리(보관 탭): `사진 저장 크기`(썸네일 480px 약 30KB 기본/작게 1280px/보통 1600px/크게 2048px, 새 사진부터 적용), `저장된 사진 줄이기`(되돌릴 수 없음, 24시간 안의 전체 백업이 있어야 실행), `사진이 큰 기록`(사진만 지우기, 글은 남음).
- 백업 알림: 글만 백업은 정한 기간(기본 14일, 보관 탭에서 변경·끄기), 사진 포함 전체 백업은 따로 정한 기간(기본 60일)이 지나면 `백업 필요`와 안내 띠가 나타납니다. 브라우저는 자동 다운로드를 허용하지 않아 자동 백업은 불가능합니다.
- `모든 기록 지우기`: 백업 파일 저장 → 저장 확인 → `지우기` 입력의 세 단계를 거쳐야 실행됩니다.
- 이전 버전의 백업 파일도 읽힙니다.

## 업데이트
방법 1(권장, 앱 안에서): 새 파일을 GitHub에 올린 뒤 폰에서 `보관` 탭 → `앱 업데이트` → `업데이트`. 새 버전이 있으면 받아서 다시 열고 "업데이트 완료"를 알려 주며, 이미 최신이면 그렇게 알려 줍니다. 기록은 유지됩니다.

GitHub에 올리기:
1. 기존 저장소 페이지에서 `Add file` → `Upload files`.
2. 압축을 푼 안쪽의 `index.html`, `sw.js`, `manifest.webmanifest`, `README.md`, `icons` 폴더를 끌어다 놓고 같은 이름으로 덮어쓰며 `Commit changes`. `sw.js`를 빠뜨리면 폰이 새 버전을 받지 못합니다.
3. 1~2분 뒤 폰에서 위의 `업데이트` 버튼을 누릅니다. (버튼이 없는 아주 오래된 버전은 앱을 완전히 종료한 뒤 두세 번 열어야 합니다.)
4. 불안하면 업데이트 전에 `보관` 탭에서 백업 파일을 저장해 두세요.

## v0.9373 변경
- 기록 탭: 검색·중요·지난 일·분류 도구를 위쪽 아이콘으로 옮기고, 칩 줄에는 전체와 분류만 남겼습니다. 검색창은 아이콘을 눌러야 펼쳐집니다.
- 입력창: 메모가 길어졌을 때만 아래쪽에 저장 버튼이 나타납니다(위쪽 저장은 항상 있음). [단일|묶음]을 두 칸 선택 버튼으로 바꿨습니다.
- 지난 일: 늦은 정도에 따라 배지 색이 3단계(어제, 2~6일, 7일 이상)로 나뉘고, 한 것은 5개만 보이며 [이전 한 것 N개 더 보기]로 펼칩니다.
- 색감: 밝은 모던 화면의 바탕을 따뜻한 색으로, 카드에 분류색 띠와 은은한 그림자를 넣었습니다.
- 쇼핑은 그대로 두고 새 분류 [돈](11번째)을 추가하고, 돈 분류에 **돈 계획**을 넣었습니다. 계획은 지출(예산 대비 사용·남음)과 저축(목표까지 남은 금액) 두 종류이며, 계획 설정에 간단한 메모를 적어 두고 계획 화면의 말풍선 아이콘으로 볼 수 있고, 기록 줄의 금액에는 '원'이 붙으며, 돈 분류의 입력 칸 이름은 '비용' 대신 '금액'입니다. 계획 안에서 금액·제목·메모 한 줄로 바로 기록합니다. 예산·목표는 비워도 되고 언제든 고칠 수 있으며 기록 금액은 바뀌지 않습니다. 계획 정보는 meta 'plans'에 저장되고 백업 파일(plans)에도 들어갑니다.
- 배포 파일은 두 가지로 만듭니다: 주석 포함 판, 사용 설명을 뺀 최소화 판.
