# 하루장 (PWA)

하루의 중요한 일을 가볍게 남기는 개인 기록장입니다(v36). 기록과 사진은 폰의 브라우저 저장소에만 저장되고 서버로 전송되지 않습니다.

## 파일 구성
- `index.html` 앱 본체
- `manifest.webmanifest` 설치 정보(이름, 아이콘, 색)
- `sw.js` 오프라인용 캐시. 배포할 때마다 안의 `VER` 값을 올려야 설치된 앱이 새 파일을 받습니다.
- `icons/` 아이콘 3개

## 올리기 (GitHub Pages, 처음 한 번)
1. github.com 에 가입하고 로그인합니다.
2. 오른쪽 위 `+` → `New repository`. 이름은 남이 추측하기 어렵게 짓습니다. 예: `harujang-k7x3q`. `Public`으로 만들고 `Create repository`.
3. `uploading an existing file` 링크를 눌러 이 폴더 안의 파일과 `icons` 폴더를 끌어다 놓고 `Commit changes`.
   (zip 파일 자체가 아니라, 압축을 푼 안쪽 파일들을 올립니다.)
4. `Settings` → `Pages` → Branch를 `main`, 폴더를 `/ (root)`로 선택하고 `Save`.
5. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소가 생깁니다.

## 폰에 설치
- 안드로이드(Chrome): 주소를 열고 오른쪽 위 메뉴(⋮) → `앱 설치` 또는 `홈 화면에 추가`. 홈 화면 아이콘으로 실행합니다. 처음 한 번만 인터넷이 필요하고 이후에는 비행기 모드에서도 열립니다.
- 아이폰(Safari만 가능): 주소를 열고 공유 버튼 → `홈 화면에 추가`. Chrome이나 카카오톡 안에서는 설치되지 않습니다.
- 설치한 앱과 브라우저 탭은 저장 공간이 따로입니다. 설치 후에는 홈 화면 아이콘으로만 여세요.

## 사용법
- 오늘 탭: `기록 남기기`(분류, 제목, 장소, 일시, 메모, 사진, 중요), `할 일 추가`(제목, 예정일, 선택 시간. `🔔 알림 등록`을 누르면 휴대전화 구글 캘린더에 일정이 채워져 열림). 할 일을 체크하면 "기록하기" 알림이 떠서 한 번에 기록으로 옮길 수 있습니다.
- 기록 탭: 날짜별 목록, 분류 필터, 중요 필터, 검색. 기록을 누르면 먼저 읽기 전용 화면이 열리고 `수정`을 눌러야 고칠 수 있습니다.
- 달력 탭: 월별 기록과 남은 할 일, 이달의 분류별 건수와 거리·비용 합계.
- 보관 탭: 분류 관리, 백업, 앱 설치 안내.
- 분류: 외출, 업무, 만남, 등산, 운동, 여행, 쇼핑, 독서, 학습, 기타 10개로 고정입니다. 분류 관리에서 표시 이름, 순서(▲▼), 숨김만 바꿀 수 있습니다. 분류에 따라 입력 항목이 다릅니다(업무·학습: 시작·종료, 등산·운동: 시작·종료와 거리, 여행·쇼핑: 비용, 독서: 저자와 읽은 쪽).
- 독서: 제목과 저자, 읽은 쪽(시작·끝·총), 메모 종류(구절·생각·더알), 완독. 구절에는 `+ 내 생각`으로 생각을 함께 남길 수 있습니다. 제목 줄의 `가져오기`로 읽은 책을 불러오고, 기록 탭의 독서 필터에서 `책별` 보기와 책 정리 내보내기를 씁니다.

## 백업
앱의 `보관` 탭 → `백업 파일 저장`. 파일은 폰의 다운로드 폴더에 저장됩니다. 구글 드라이브나 PC로 옮겨 두세요. 폰을 바꾸거나 브라우저 데이터를 지웠을 때 `백업 불러오기`로 되돌리며, 같은 기록은 수정 시각이 더 새로운 쪽이 남습니다. `읽기용(마크다운) 저장`은 읽고 보관하는 용도이며 복원에는 쓸 수 없습니다. 이전 버전의 백업 파일도 읽힙니다.

## 업데이트
1. 기존 저장소 페이지에서 `Add file` → `Upload files`.
2. 압축을 푼 안쪽의 `index.html`, `sw.js`, `manifest.webmanifest`, `README.md`, `icons` 폴더를 끌어다 놓고 같은 이름으로 덮어쓰며 `Commit changes`. `sw.js`를 빠뜨리면 폰이 새 버전을 받지 못합니다.
3. 1~2분 뒤 폰에서 앱을 완전히 종료했다가 두 번 엽니다(두 번 열어야 바뀝니다). 기록은 폰에 있으므로 그대로 유지됩니다.
4. 불안하면 업데이트 전에 `보관` 탭에서 백업 파일을 저장해 두세요.
