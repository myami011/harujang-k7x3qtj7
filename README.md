# 하루장 (PWA)

개인용 하루 기록장입니다(v2: 기록 + 할 일 + 분류 관리). 기록과 사진은 폰의 브라우저 저장소에만 저장되고 서버로 전송되지 않습니다.

## 파일 구성
- `index.html` 앱 본체
- `manifest.webmanifest` 설치 정보(이름, 아이콘, 색)
- `sw.js` 오프라인용 캐시
- `icons/` 아이콘 3개

## 올리기 (GitHub Pages, 처음 한 번)
1. github.com 에 가입하고 로그인합니다.
2. 오른쪽 위 `+` → `New repository`. 이름은 남이 추측하기 어렵게 짓습니다. 예: `harujang-k7x3q`. `Public`으로 만들고 `Create repository`.
3. `uploading an existing file` 링크를 눌러 이 폴더 안의 파일과 `icons` 폴더를 끌어다 놓고 `Commit changes`.
   (zip 파일 자체가 아니라, 압축을 푼 안쪽 파일들을 올립니다.)
4. `Settings` → `Pages` → Branch를 `main`, 폴더를 `/ (root)`로 선택하고 `Save`.
5. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소가 생깁니다.

## 폰에 설치 (안드로이드)
1. Chrome으로 위 주소를 엽니다. 처음 한 번은 인터넷이 필요합니다.
2. 오른쪽 위 메뉴(⋮) → `앱 설치` 또는 `홈 화면에 추가`.
3. 홈 화면 아이콘으로 실행합니다. 이후에는 비행기 모드에서도 열립니다.

## 백업
앱의 `보관` 탭 → `백업 파일 저장`. 파일은 폰의 다운로드 폴더에 저장됩니다. 구글 드라이브나 PC로 옮겨 두세요. 폰을 바꾸거나 브라우저 데이터를 지웠을 때 `백업 불러오기`로 되돌립니다.

## 사용법
- 오늘 탭: `기록 남기기`(제목·분류·메모·사진·별), `할 일 추가`(제목·예정일). 할 일을 체크하면 "기록하기" 알림이 떠서 한 번에 기록으로 남길 수 있습니다.
- 분류: `보관` 탭 → `분류 관리`에서 이름·색 변경, 추가, 삭제(삭제하면 기록은 기타로 이동).
- v1 백업 파일도 `백업 불러오기`로 읽힙니다.

## 기존 사이트를 v2로 업데이트
1. 기존 저장소 페이지에서 `Add file` → `Upload files`.
2. 압축을 푼 안쪽의 `index.html`, `sw.js`, `manifest.webmanifest`, `README.md`, `icons` 폴더를 끌어다 놓고 같은 이름으로 덮어쓰며 `Commit changes`.
3. 1~2분 뒤 폰에서 앱을 열었다가 완전히 닫고 다시 엽니다(두 번 열어야 바뀝니다). 기록은 폰에 있으므로 그대로 유지됩니다.
4. 불안하면 업데이트 전에 `보관` 탭에서 백업 파일을 저장해 두세요.
